# Facturas VB.NET

Aplicación de escritorio para la gestión de facturación, desarrollada en **VB.NET y Windows Forms**.

Este proyecto constituye la versión original de una aplicación de facturación que posteriormente fue convertida a C#.

## Funcionalidades

La aplicación incluye, entre otras, funcionalidades para:

- Gestión de clientes y proveedores.
- Gestión de materiales.
- Gestión de albaranes.
- Facturas de venta y de compra.
- Facturas de abono.
- Aplicación de descuentos e IVA.
- Consultas y listados de compras y ventas.
- Generación de informes y facturas mediante Crystal Reports.

## Tecnologías

- VB.NET
- .NET Framework
- Windows Forms
- SQL Server
- ADO / ADO.NET
- Crystal Reports
- Visual Studio

## Base de datos

La aplicación utiliza una base de datos SQL Server denominada `Facturas`.

Las credenciales utilizadas en el entorno original de desarrollo han sido eliminadas del repositorio. Las cadenas de conexión contienen `CHANGE_ME` como marcador y deben configurarse con las credenciales correspondientes antes de ejecutar la aplicación.

## Evolución del proyecto

Esta es la versión original desarrollada en VB.NET.

Posteriormente, la aplicación fue convertida a C#. La versión C# está disponible en:

https://github.com/juanantonioadanranera/Facturas-CSharp

Ambos repositorios se conservan para mostrar la evolución del proyecto entre VB.NET y C#.
